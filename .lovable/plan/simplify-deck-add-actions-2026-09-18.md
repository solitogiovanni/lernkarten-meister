# Simplify deck add actions

## Goal
Make search-based adding the only add path on the Nouns page and simplify the actions shown beneath search results on every device.

## Changes
- Remove the individual Noun, Verb, Adjective, and Adverb add buttons beneath cross-deck search results on all screen sizes.
- Enlarge the **Auto-detect type** button on phones, tablets, and desktops.
- Add a similarly sized **Add to Grammar** button beside Auto-detect; it opens the Grammar add panel with the current search text filled into the title.
- Remove the top **Add noun** button from the Nouns page on all devices.
- Keep the existing auto-detect and Grammar save behavior unchanged.

## Verification
- Check the Nouns page and another deck at phone and desktop widths.
- Confirm only Auto-detect and Add to Grammar appear beneath search results.
- Confirm Add to Grammar opens the Grammar add panel with the searched text.
- Confirm the Nouns header no longer shows Add noun.
